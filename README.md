## Project Description

### Domain
Home food inventory and meal planning: tracking the ingredients a household already has on hand and using them to decide what to cook.

---

## User Stories

### User Story 1
As someone who keeps a kitchen, I want to record what I have, how much of it, and when it goes off, so that I can see everything in my pantry in one place.

### User Story 2
As someone who hates wasting food, I want to see what’s about to expire and be able to mark each item as used or thrown out, so that I can deal with food before it spoils. 

### User Story 3
As someone who shops weekly, I want to be able to create my own shopping lists and add items to shopping lists, so that I know what to buy when I get to the store. 

### User Story 4
As someone deciding what to make for dinner, I want recipe suggestions that use what’s actually in my pantry right now, with the things expiring soonest used first, so that I can cook without shopping.

### User Story 5
As someone who wants accurate inventory records, I want to see what I bought, what I used, what I wasted over time so that I can stop repurchasing the items I consistently waste.
