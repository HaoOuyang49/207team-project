## Project Description

### Domain

Data Analysis Platform

TTC Delay Tracker is a planned Java Swing desktop application that uses historical delay data released by the Toronto Transit Commission (TTC). It will help riders explore past delays, view patterns by time and station, and assess and compare their commute options.

---

## User Stories

### User Story 1

As a rider, I want to search and filter past delays by line, station, date, and cause to be able to see exactly what's been going wrong where I travel.

### User Story 2

As a rider, I want to see a heatmap of delays by hour and day of the week to be able to know when the TTC is least reliable.

### User Story 3

As a rider, I want to view a subway map with stations coloured by how often they're delayed to be able to spot the worst stations at a glance.

### User Story 4

As a commuter, I want to save my regular commute and get a reliability score for it to be able to know how much extra time to plan for.

### User Story 5

As a commuter, I want to compare my usual route against alternatives (e.g. subway vs. streetcar) to be able to pick the most reliable way to get where I'm going.
